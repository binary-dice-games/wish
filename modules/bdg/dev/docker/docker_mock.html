Docker frontend — UI mockup

A Docker Desktop–style GUI over the local docker CLI. Six independently dockable windows, git-module style: list views for containers / images / volumes / networks, plus Logs and Inspect. All docker calls run client-side; the server form only renders.

Static stand-in. This page mirrors the widget tree in docker_mock.json (which renders live in the editor tool — verified). It exists to review columns, toolbars, and the confirm-gating at full width in one view. Sample rows are illustrative, not real daemon output.

Client → server render methods: update_containers, update_images, update_volumes, update_networks, update_logs, update_inspect, command_result.

Refresh is manual: a Refresh button per window plus an automatic refresh after every mutating action — no background polling (the git module's jitter lesson). The Logs “Follow” toggle is a 2 s client-side re-poll, not docker logs -f streaming. Full rationale in modules/bdg/dev/docker/DESIGN.md.
