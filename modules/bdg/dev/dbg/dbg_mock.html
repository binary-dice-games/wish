Debugger frontend — UI mockup

A VS Code–style debugger over Windows' native debug API. The client attaches to a process, drives DebugActiveProcess/WaitForDebugEvent and DbgHelp symbol resolution locally; the server only renders six independently dockable windows from the snapshots it's sent. No OS debug-API call is ever made server-side.

Static stand-in. This page previews the real docked arrangement described in DESIGN.md §3; dbg_mock.json (which renders live in the editor tool) shows the same six windows as tabs instead, since the editor tool can't preview multiple independently dockable windows at once. Sample rows/values are illustrative, not a real attach. The breakpoint dot and current-line arrow in the Source gutter below are what TextEditor's new breakpoint_lines/current_line fields (Step 2) will actually draw via SetLineDecorator — today's TextEditor has no such gutter.
